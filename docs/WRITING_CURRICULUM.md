# 雅思写作课程大纲（Writing Curriculum）

AI 老师出写作题时按此路线推进：**先句子、再图表、后文章**。每阶段通过多轮练习 + 验证卷过关后再进入下一阶段。

## 进阶路线总览

```
Stage 1  话题短句（句子级）     语法结构 × 雅思话题，每句 1-2 句
   ↓ 高频结构 5+ 个全对
Stage 2  小作文 Task 1（图表级） line / bar / pie / table / process / map 模板
   ↓ 6 类图表各练 1 篇迷你版
Stage 3  大作文 Task 2（文章级） 5 类题型模板 + 段落结构
   ↓ 每类题型练过且结构达标
进阶      限时模拟 + 高频话题素材积累
```

## Stage 1 · 雅思话题短句

**目标**：把一个语法结构和一个雅思话题绑定成肌肉记忆，为后面的图表和文章打地基。

**练习形式**：每题给「话题 + 必用结构 + 提示词」，写 1-2 句；每题 2 分，rubric 三项：结构用对、语法准确、话题词汇。

**高频结构 × 五大话题矩阵**（出题从矩阵里取，循序渐进）：

| 结构 | 教育 | 城市 | 环保 | 健康 | 工作 |
|---|---|---|---|---|---|
| 现在完成时 | ✓ | | ✓ | | ✓ |
| 比较级 | ✓ | ✓ | | ✓ | ✓ |
| 被动语态 | | ✓ | ✓ | ✓ | |
| because 原因 | ✓ | | ✓ | ✓ | |
| although 让步 | | ✓ | | | ✓ |
| if 条件句 | ✓ | ✓ | | ✓ | ✓ |
| 定语从句 | ✓ | ✓ | ✓ | | ✓ |
| 动名词作主语 | | ✓ | | ✓ | ✓ |

**过关标准**：每个结构至少两次满分，或一次满分 + 一次 ≥1.5/2。

## Stage 2 · 小作文 Task 1（图表模板）

**六类图表**，每类练习按「模板填空 → 独立描述」两步：

| 类型 | 模板要点 | 高频句式 |
|---|---|---|
| line 折线 | 趋势动词（rise/fall/remain stable）、幅度副词 | The figure rose sharply before levelling off. |
| bar 柱状 | 对比 + 极值（highest/lowest） | A was the most common choice, at 40%. |
| pie 饼图 | 占比（account for / make up） | X accounted for the largest proportion. |
| table 表格 | 排序 + 多维度对比 | In terms of X, A ranked first. |
| process 流程 | 步骤顺序（first/then/finally）+ 被动 | The material is then heated to 200°C. |
| map 地图 | 方位（north of / adjacent to）+ 变化 | The area was converted into a residential zone. |

**练习形式**：给图表数据（文字描述即可），写 3-5 句描述；rubric：概述句、数据引用、时态、比较。

**过关标准**：每类图表 1 篇迷你练习 ≥70%。

## Stage 3 · 大作文 Task 2（题型模板）

**五类题型**：

| 题型 | 结构模板 | 连接词 |
|---|---|---|
| Opinion（同意与否） | 立场段 ×2-3 + 让步段 + 结论 | I believe / admittedly |
| Discussion（双方讨论） | 一方观点 + 另一方观点 + 我的立场 | Some argue…; however… |
| Advantages/Disadvantages | 利 ×2 + 弊 ×2 + 权衡结论 | On the one hand… |
| Problem/Solution | 问题 ×2 + 措施 ×2 + 展望 | This problem stems from… |
| Double Question | 两个问题各答一段 | As for the second question… |

**练习形式**：每类题型给题 → 先写段落（主体段 1 段，60-100 词）→ 过关后写全文（4 段，250 词）。

**过关标准**：段落练习 rubric 达标（结构完整、观点清晰、连接词、语法准确率 ≥90%）。

## 通用 rubric 要点（AI 批改用）

1. **Task Response**：是否回答了所有要求点
2. **结构**：模板结构是否完整（模板练习阶段重点）
3. **语法准确性**：错一处扣 0.5，同类型错只扣一次
4. **词汇**：提示词是否用上、话题搭配是否地道
5. 每道写作题 `answer.rubric` 写具体三到四条评分点，按点给分

## 出题纪律

- 一次只练一个结构/一种图表/一类题型，多轮验证
- 写作出题必须有提示词和明确句数/词数限制
- `explanation` 字段放示范句/范文（批改后给学生对照）
- 题目语境永远用雅思话题：教育 / 环保 / 科技 / 城市 / 健康 / 工作
